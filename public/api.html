所有公开 API 端点返回统一错误格式：

{

    "code": "ERROR_CODE",

  }
}

401API_KEY_REQUIRED需要 API Key

413PAYLOAD_TOO_LARGE请求体超过大小限制

CORS 跨域

CORS 默认关闭。启用方式：设置环境变量 CORS_ORIGINS。

# 允许所有来源
set CORS_ORIGINS=*
node server.js

# 允许指定来源（逗号分隔）
set CORS_ORIGINS=https://example.com,https://app.example.com
node server.js

启用后，所有 /api/ 路径的响应将携带适当的 CORS 头，并支持 OPTIONS 预检请求。

公开数据 API

GET/api/v1/earthquakes

多源实时地震数据。服务器端合并 USGS GeoJSON + 本地多源地震 API（EMSC、P2PQuake、Wolfx、GEOFON 等），非 USGS 事件自动注入为 GeoJSON Feature。30 秒内存缓存。

响应 200

// GeoJSON FeatureCollection（合并多源数据）
{
  "type": "FeatureCollection",
  "metadata": { "sources": ["usgs", "emsc", "p2pquake", "wolfx_eq", "geofon"] },
  "features": [
    { "type": "Feature", "id": "us7000xxx",
      "properties": { "mag": 5.2, "place": "...", "source": "USGS", ... },
      "geometry": { "type": "Point", "coordinates": [lng, lat, depth] }
    },
    { "type": "Feature", "id": "live-123",
      "properties": { "mag": 4.8, "place": "...", "source": "EMSC", "sources": ["emsc", "wolfx_eq"], ... },
      "geometry": { "type": "Point", "coordinates": [lng, lat, depth] }
    }
  ]
}

每个 feature 的 properties.source 标注数据来源，metadata.sources 列出本次响应的所有活跃数据源。

GET/api/v1/waveform

通过 FDSN 同时获取 MiniSEED 与 StationXML 仪器响应（Python ObsPy，数据源：IRIS / GFZ），去除响应后以加速度 gal 返回。三分量分析请求会校验分量完整性、数据缺口、重采样与来源；不满足条件时明确标记为不可科研认证。兼容字段 data[] 继续保留。

查询参数

参数类型默认说明
stationstringMAJO台站代码（1-5 位大写字母/数字）
networkstringIU台网代码（1-2 位大写字母/数字）
channelstringBHZ通道代码（3 位大写字母/数字）：BHZ=垂直速度，BHN/BHE=水平
locationstring*FDSN location code
hoursnumber1数据时长（1-24 小时）
durationSecondsnumber—覆盖 hours，限制 60-3600 秒
components1 / 31请求单分量或三分量
purposedisplay / analysisdisplay分析模式保留更多采样点并执行科研输入门禁
endtimeISO 8601当前时间历史波形窗口结束时间

响应 200

{
  "_schema": "quake-sim-waveform-v1",
  "type": "waveform",
  "units": "gal",
  "quality": {"researchReady": true, "responseRemoved": true, "reasons": []},
  "provenance": {"provider": "IRIS", "sourceUrl": "https://service.iris.edu/fdsnws/"},
  "components": {"z": {"channel": "BHZ", "samples": [1.23, -4.56], "sha256": "..."}},
  "data": [{
    "id": "IU.MAJO.00.BHZ",
    "network": "IU",
    "station": "MAJO",
    "channel": "BHZ",
    "starttime": "2026-06-30T12:00:00.000000Z",
    "sampling_rate": 50,
    "npts": 5000,
    "max_amplitude": 12.3,
    "unit": "gal",
    "samples": [1.23, -4.56, 2.10, ...]
  }]
}

响应字段

字段说明
components响应校正后的 Z/N/E 加速度数组与逐分量 SHA-256
quality科研就绪状态及缺分量、缺口、重采样等拒绝原因
provenance数据中心、来源 URL、获取时间和原始请求
data供旧客户端使用的兼容波形数组，单位同样为 gal
sampling_rate交付采样率 Hz
starttime第一个采样点的 UTC 时间，配合采样率可重建时间轴
max_amplitude采样点绝对值的最大值（可用于快速判断信号强度）
unitgal，即已去除仪器响应的加速度 cm/s²

解析示例

// JavaScript — 绘制波形到 Canvas
const resp = await fetch('/api/v1/waveform?station=MAJO&hours=2');
const { data } = await resp.json();
const tr = data[0];

const canvas = document.getElementById('my-canvas');
const ctx = canvas.getContext('2d');
const w = canvas.width, h = canvas.height;
const maxAmp = tr.max_amplitude || 1;

ctx.beginPath();
for (let i = 0; i < tr.samples.length; i++) {
  const x = (i / tr.samples.length) * w;
  const y = (0.5 - tr.samples[i] / (2 * maxAmp)) * h;
  i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
}
ctx.stroke();
# Python — matplotlib 绘图
import requests, matplotlib.pyplot as plt

resp = requests.get("http://localhost:3000/api/v1/waveform?station=MAJO")
tr = resp.json()["data"][0]
sr = tr["sampling_rate"]
t = [i / sr for i in range(len(tr["samples"]))]

plt.plot(t, tr["samples"], linewidth=0.5)
plt.xlabel(f"Time (s) since {tr['starttime']}")
plt.ylabel(f"Amplitude ({tr['unit']})")
plt.title(f"{tr['id']} — {tr['npts']} samples @ {sr}Hz")
plt.show()

GET/api/v1/p2pquake/stream 最大 200 连接

Server-Sent Events (SSE) 实时推送日本地震数据。数据来源：P2PQuake、Wolfx JMA EEW、Wolfx 地震列表、EMSC、JMA Atom Feed。

SSE 事件格式

data: {"type":"p2pquake","event":{"id":"p2pq_...","code":5611,"mag":5.2,"lat":35.6,"lng":139.8,"depth":50,"place":"...","maxShindo":"4","time":"...","serial":1}}

事件类型：p2pquake（地震）、wolfx_eew（紧急地震速报）、wolfx_eq（地震列表）、emsc（全球地震）、jma_feed（JMA XML）。每 30 秒心跳保持连接。

客户端示例

const es = new EventSource('/api/v1/p2pquake/stream');
es.addEventListener('message', (e) => {
  const { type, event } = JSON.parse(e.data);
  console.log(type, event.mag, event.place);
});

实时监控与回放 API

服务器把 SSE 实时帧持续录制到内存环形缓冲（保留 3 小时 / 20,000 帧）并按天追加到 recordings/YYYYMMDD.jsonl.gz（保留 3 天），以下端点用于回放与导出；另含 NIED 強震モニタ 与校时/定位代理。

GET/api/v1/replay/info

回放录制器状态 + 事件时间线索引（每个 EEW EventID 一个标记 + 震度3+ 的 551 速报，最多 200 条，新的优先保留）。Cache-Control: no-cache。

curl http://localhost:3000/api/v1/replay/info
{
  "ok": true,
  "earliest": 1786626828027, "latest": 1786637627421, "frames": 16648,
  "byType": {"kmoni_rt": 10288, "jma_feed": 6258, "wolfx_eq": 100, "p2pquake": 2},
  "diskBytes": 17736025,
  "events": [{"t": 1786511589845, "type": "eew", "label": "EEW M5.9 プローブ震源地"}]
}
GET/api/v1/replay/stream 最大 20 连接

SSE 回放已录制的实时帧（仅内存环形缓冲窗口）。每帧以命名事件 event: <type> 发送，data 为 {"type","event","replayTs"}；结尾发送 event: replay_end 后关闭。

参数类型默认说明
speednumber5回放倍速（0.25 ~ 120）
fromint环形缓冲最旧帧起始时刻（epoch ms），更早的帧跳过
curl -N "http://localhost:3000/api/v1/replay/stream?speed=60"
GET/api/v1/replay/export 窗口 ≤ 6 小时

按时间窗口下载录制帧（NDJSON，每行 {"t","type","event"}）。窗口自动收窄到可用录制范围（日线文件保留 3 天）；窗口内无帧返回 204；超过 6 小时返回 400。

参数类型必填说明
fromint是窗口起点（epoch ms）
toint是窗口终点（epoch ms，≥ from）
curl -OJ "http://localhost:3000/api/v1/replay/export?from=1786637000000&to=1786640000000"
# → quake-replay-<from>-<to>.jsonl (application/x-ndjson)
GET/api/v1/kmoni/sitelist

NIED 強震モニタ 测站列表代理（上游为 Yahoo 边缘镜像）。上游响应缓存 1 小时；响应头 Cache-Control: public, max-age=300；上游失败但有缓存时返回旧数据，否则 502。返回 {"siteConfigId", "items": [[lat,lng], ...]}，items 下标与 kmoni_rt 帧的 intensity 字符一一对应。

curl http://localhost:3000/api/v1/kmoni/sitelist
GET/api/v1/kmoni/image

NIED 官方实时震度图（RealTimeImg，GIF/PNG）。候选源按顺序探测（nied-new → nied-old → yahoo），可用源复用 60 秒；图像体缓存 5 秒。全部失败时退避 60 秒：有旧图返回旧图，否则 503 UPSTREAM_ERROR + Retry-After: 60。成功响应带 X-Kmoni-Image-Time（帧时刻）与 X-Kmoni-Image-Source（来源）头。

curl -O http://localhost:3000/api/v1/kmoni/image
GET/api/v1/ntp

Wolfx NTP 校时代理（用于客户端时钟偏移校准）。缓存 60 秒；上游失败时返回旧缓存，否则 502。响应：{"JST":{"str","int"},"CST":{"str","int"},"timestamp":<epoch ms>}。

curl http://localhost:3000/api/v1/ntp
GET/api/v1/geoip

Wolfx GeoIP 代理，转发访客 IP 做粗略定位（EEW 倒数参考点；本地/内网 IP 使用服务器侧默认值）。Cache-Control: private, max-age=300；上游失败返回 502。

curl http://localhost:3000/api/v1/geoip
GET/api/v1/waveform/live

实时多台站波形代理（v6.2 实时监测升级）。冻结白名单 4 个环绕日本的开放 GSN 台站（IU MAJO 松代 / YSS 南萨哈林斯克 / INCN 仁川 / TATO 台湾坪林，location 00 · BHZ），上游为 EarthScope NGF FDSN dataselect（匿名开放数据，2026-09-03 验证），服务端解码 miniSEED STEIM1/2（libmseed 权威语义移植）。返回值为仪器原始计数（counts），未做任何标定，不构成烈度或物理单位。windowSec 量化到 60 秒步长（60–1200，默认 600）；30 秒键控 LRU 缓存 + 10 分钟 stale-if-error；上游 204 无数据如实返回 nodata:true（绝不伪造平线）；EEW 跟踪事件时面板叠加 P/S 预计到时刻度。参数：sta（白名单）、windowSec。错误：403 白名单外台站 / 429 超限（20/min/IP）/ 502 上游失败且无新鲜缓存。

curl "http://localhost:3000/api/v1/waveform/live?sta=MAJO&windowSec=600"
GETPOST/api/settings

本机设置（v6.0.1）。GET 公开返回生效的 TTS 上游配置（无任何机密——设置页保存的 API key 只写不回显）。POST 仅允许回环地址（远程访问 403，SSRF 防护；10 次/分钟）：ttsUpstreamUrl（http(s) URL，空串恢复默认）、ttsApiKey（可打印 ASCII，空串清除）、ttsApiKeyMode（query | bearer | x-api-key）。设置即时生效无需重启；TTS_UPSTREAM_URL 环境变量存在时优先且不可改。

curl http://localhost:3000/api/settings
curl -X POST http://localhost:3000/api/settings -H "Content-Type: application/json" -d '{"ttsUpstreamUrl":"http://127.0.0.1:7896/tts"}'

Webhook API

让外部服务订阅地震模拟器的事件。地震发生时、TTS 速报生成时、数据源状态变化时，服务器会主动 POST 到注册的 URL。

⚠ 安全提示：Webhook 功能涉及服务器主动向外部 URL 发送请求。请务必保护好 API Key，避免泄露给不可信的第三方。如果不需要此功能，可通过环境变量 WEBHOOKS_ENABLED=false 完全关闭。所有 webhook 操作均需 API Key 鉴权。
限制：每个 API Key 最多 10 个 webhook，URL 必须以 http:// 或 https:// 开头。注册后服务器会发送验证 ping，接收方须 5 秒内返回 200 且响应体包含 challenge 字符串。

// 接收方验证签名（Node.js 示例）
const crypto = require('crypto');
const sig = req.headers['x-quakesim-signature'];
const expected = 'sha256=' + crypto.createHmac('sha256', SECRET).update(rawBody).digest('hex');
if (!crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected))) {
  res.status(401).json({ error: 'Invalid signature' });
}

Web Audio API 播放 TTS 速报

async function playBulletin(fragments) {
  const ctx = new AudioContext();
  let t = ctx.currentTime + 0.1;
  for (const frag of fragments) {
    const resp = await fetch(frag.path);
    const buf = await ctx.decodeAudioData(await resp.arrayBuffer());
    const src = ctx.createBufferSource();
    src.buffer = buf;
    const gain = ctx.createGain();
    gain.gain.value = frag.vol;
    src.connect(gain).connect(ctx.destination);
    src.start(t);
    t += buf.duration;
  }
}

const resp = await fetch('/api/v1/tts/bulletin', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ lang:'zh', mag:7.0, depth:30, maxShindo:'6+' })
});
const { fragments } = await resp.json();
playBulletin(fragments);

curl + ffplay 命令行播放

curl -s -X POST http://localhost:3000/api/v1/tts/bulletin \
  -H 'Content-Type: application/json' \
  -d '{"lang":"jp","mag":7.0,"depth":30,"maxShindo":"6+"}' \
  | jq -r '.fragments[].path' \
  | while read url; do ffplay -nodisp -autoexit "$url"; done

SSE 实时地震监听

const es = new EventSource('/api/v1/p2pquake/stream');
es.addEventListener('message', (e) => {
  const { type, event } = JSON.parse(e.data);
  if (type === 'p2pquake') {
    console.log(`M${event.mag} — ${event.place} (震度${event.maxShindo})`);
  }
});
es.onerror = () => console.log('SSE disconnected, retrying...');
